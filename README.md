# Little Lemon Capstone — carpeta de trabajo

Esta carpeta es una guía y estructura inicial para desarrollar el proyecto del Curso 8. No es una entrega terminada y contiene marcadores `TODO` que debes implementar y comprender antes de subirla a Coursera.

## Estructura

- `PROJECT_CHECKLIST.md`: requisitos de la rúbrica y control de avance.
- `STUDY_GUIDE.md`: temas para preparar los quizzes de los módulos 2 y 3.
- `sql/01_schema_template.sql`: plantilla para diseñar el esquema relacional.
- `sql/02_queries_and_procedures_template.sql`: plantilla para vistas y procedimientos.
- `python/database_client_template.py`: plantilla segura para el cliente MySQL.
- `tableau/TABLEAU_CHECKLIST.md`: pasos y evidencias para Tableau.
- `diagrams/README.md`: requisitos del diagrama ER.
- `data/README.md`: ubicación y cuidado del archivo de datos.

## Cómo empezar

1. Crea un repositorio vacío en GitHub para tu proyecto.
2. Copia esta estructura a tu repositorio.
3. Diseña primero el modelo ER y completa `sql/01_schema_template.sql`.
4. Prueba el esquema en tu propia instancia de MySQL.
5. Implementa y prueba los procedimientos uno por uno.
6. Completa el cliente Python y después el análisis en Tableau.
7. Marca únicamente los puntos de `PROJECT_CHECKLIST.md` que hayas probado personalmente.

No guardes contraseñas, tokens ni datos sensibles dentro del repositorio.

# Checklist de Tableau

- [ ] Descargar personalmente el archivo `LittleLemon_data.xlsx` desde Coursera.
- [ ] Abrir una fuente de datos nueva en Tableau.
- [ ] Revisar y corregir tipos de datos.
- [ ] Identificar dimensiones y medidas.
- [ ] Crear al menos un campo calculado relevante.
- [ ] Crear hojas que respondan preguntas concretas de ventas y beneficios.
- [ ] Usar títulos, etiquetas y colores legibles.
- [ ] Crear un dashboard que reúna las hojas relevantes.
- [ ] Agregar filtros o acciones que demuestren interactividad.
- [ ] Probar el dashboard con distintas selecciones.
- [ ] Guardar el workbook y capturas PNG en el repositorio.

Para cada visualización, anota:

1. Pregunta de negocio.
2. Campos utilizados.
3. Tipo de gráfico y por qué es apropiado.
4. Hallazgo principal.

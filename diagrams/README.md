# Diagrama ER

El diagrama debe ser creación tuya y corresponder exactamente al SQL final.

Comprueba que incluya:

- Entidades necesarias para clientes, reservas, pedidos, menú y personal.
- Clave primaria en cada tabla.
- Claves foráneas visibles.
- Cardinalidad de cada relación.
- Nombres consistentes con el archivo SQL.
- Tipos de datos y restricciones importantes.

Exporta una imagen PNG legible y guarda también el modelo de MySQL Workbench.
